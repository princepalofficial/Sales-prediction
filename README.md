Sales Prediction Using Machine Learning 📊

About the Project

This project predicts sales using Machine Learning and Python.

It uses Linear Regression to learn the relationship between advertising, price, discount, customers, and sales.

This project helped me understand the basics of Machine Learning, data analysis, and sales prediction.

Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

Features

- Creates a sample sales dataset
- Cleans the data
- Splits data into training and testing sets
- Trains a Linear Regression model
- Predicts sales for new data
- Evaluates model performance
- Creates a graph of actual and predicted sales

Installation

Step 1: Clone the Repository

git clone https://github.com/princepalofficial/Sales-prediction.git

Step 2: Open the Project Folder

cd Sales-prediction

Step 3: Install Required Libraries

pip install -r requirements.txt

Step 4: Run the Project

python "Sales Prediction.py"

Machine Learning Model

This project uses Linear Regression to predict sales.

The dataset includes:

- Advertising
- Price
- Discount
- Customers

The target variable is Sales.

The data is divided into training and testing sets to evaluate the model.

Model Evaluation

The model is evaluated using:

- MAE: Measures the average absolute prediction error.
- RMSE: Measures prediction error while giving larger errors more weight.
- R² Score: Shows how well the model explains variation in the test data.

The evaluation results are printed when the program runs.

Sample Prediction

The program uses sample values for advertising, price, discount, and customers to predict sales.

The prediction is an estimate, not a guarantee of actual sales.

Limitations

- The project uses a synthetic dataset.
- The results may not represent real business sales.
- The model has not been tested on real-world sales data.
